Acepta CSV y Excel. Las columnas que entiende son codigo, nombre, apellido, correo, cargo, cargo_codigo, sucursal, sucursal_codigo y codigo_supervisor. Los acentos y las mayúsculas del encabezado no importan.

El código es la identidad de cada persona: si ya existe se actualiza, si no se crea. Reimportar la misma planilla no duplica a nadie.

Con las sucursales y los cargos la regla es: si la planilla trae el nombre, se crea lo que falte; si trae solo el código, tiene que estar cargado de antes —con un código suelto no hay con qué nombrarlo—. Las columnas de código son opcionales.

El rol no se importa: todo el mundo entra como colaborador. Los administradores se nombran después, uno por uno, desde el directorio. Volver a importar la nómina no se los quita.
